Vehicle Info API

עוטף את שירות בדיקת הרכב לפי מספר לוחית רישוי. עותק סטטי של החוזה — ללא Swagger UI חי, בכוונה, כדי לשמור על שתי תלויות בלבד (express, zod).

POST /vehicle-info

מבקש פרטי רכב לפי מספר לוחית רישוי.

curl -X POST https://car-insurance-onboarding.vercel.app/vehicle-info \
  -H "Content-Type: application/json" \
  -d '{"license_plate": "12345678"}'

תגובת הצלחה — 200

{
  "success": true,
  "data": {
    "license_plate": "12345678",
    "manufacturer": "טויוטה",
    "model": "קורולה",
    "year": 2020,
    "color": "לבן"
  }
}
